An original open-world crime game for make.fun's "Make GTA 6" bounty: explore the sun-soaked coastal city of Solmar Bay on foot and by car, steal cars, outrun the police, and run three story missions for fixer Marisol Vega. Built with three.js; plays offline in a desktop browser from static files, no network needed.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
